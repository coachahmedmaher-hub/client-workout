# Client Workouts — Coach Ahmed Maher

موقع التمارين. العميل بيختار الأول رجل أو امرأة (وشكل الموقع بيتغيّر على حسب اختياره)، وبعدين يكتب الكود بتاعه، فيظهر له تمرينه.

## شكل الملفات على GitHub لازم يبقى كده بالظبط

```
index.html
admin.html
README.md
.nojekyll
assets/      ← فولدر فيه 9 ملفات (config.js, crypto.js, i18n.js, anatomy.js, workout.js, style.css, والأيقونات)
workouts/    ← فولدر فيه ملفات العملاء (.json)
```

## تمرين جديد لعميل

1. افتح `.../admin.html`.
2. اكتب اسم العميل، ودوس **كود جديد** (أو اكتب نفس كوده في موقع التغذية)، وعدّل التمارين.
   - لو العميل بيتمرن كذا يوم، دوس **+ يوم** واكتب تمارين كل يوم. العميل هيلاقي أزرار Day 1، Day 2… ولما يدوس على أي يوم تظهر تمارينه.
3. دوس **معاينة**، وبعدين **اعمل ملف التمرين**.
4. ارفع الملف اللي نزل جوه فولدر `workouts`، وابعت للعميل اللينك والكود.

## الأوزان والتكرارات

الأرقام بتتحفظ على موبايل العميل نفسه. لو غيّر الموبايل أو المتصفح أو مسح بياناته، الأرقام القديمة مش هتظهر، بس التمرين نفسه بيفضل موجود بالكود.

## صور التمارين

- الصور في فولدر `images`، وقايمتها في ملف `assets/photos.js`.
- لإضافة صورة: ارفعها في `images` باسم التمرين بحروف صغيرة وشُرط (مثلًا `hip-thrust-machine.jpg`)، وزوّد سطر في `assets/photos.js`:
  `"hip-thrust-machine": ["hip-thrust-machine.jpg"],`
- زرار **Photo** بيظهر لوحده في أي تمرين له صورة، عند كل العملاء.
